Blood Donor Finder and Emergency Request System


Built a real-time blood donor assistance system to connect patients with nearby donors during emergencies. The application improves accessibility to blood resources by providing fast donor search and emergency request features. The system was developed using Python for backend processing, MySQL for data storage, and HTML and CSS for the user interface.

Technologies Used: Python (Backend Development), HTML & CSS (Frontend), MySQL (Relational Database),SQL
