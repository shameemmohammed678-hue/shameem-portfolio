MusicHub


MusicHub is a full-stack music player built with React and Django REST Framework. It includes JWT authentication, song search and playback, favorites, playlists, and an admin upload system using Cloudinary, with TiDB Cloud for database management.

Technologies Used:HTML5, CSS3,JavaScript,React,Python,Django,Tidb cloud ,MySQL,Vercel,Git, GitHub
