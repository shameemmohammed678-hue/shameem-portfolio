Blood Donar Finder and Emergency Request System


Developed and deployed a full-stack web application that connects hospitals with nearby blood donors during emergencies through real-time donor search and emergency request management. Implemented secure donor, hospital, and admin modules with authentication, SMS notification integration, and cloud-hosted database connectivity. Successfully deployed the application on Vercel with a TiDB Cloud (MySQL-compatible) database, using GitHub for version control and deployment automation.

Technologies Used: Python, Flask, HTML, CSS, MySQL (TiDB Cloud), SQL, PyMySQL, Vercel, Git, GitHub, Twilio API
